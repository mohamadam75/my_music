# my_music — موزیک من

وب‌اپ فارسی/RTL برای جست‌وجوی موسیقی چندزبانه، پلی‌لیست ستاره‌دار و ذخیره‌ی فایل‌های صوتی روی دستگاه.

## امکانات وب
- جست‌وجوی کاتالوگ آهنگ‌ها از iTunes و جست‌وجوی متنی LRCLIB؛ تلاش برای دریافت نتایج Deezer نیز انجام می‌شود و به دسترسی شبکه/CORS وابسته است.
- لینک‌های تکمیلی برای YouTube، متن آهنگ، عکس کاور، Instagram و SoundCloud.
- ستاره‌دار کردن و نگه‌داری اطلاعات آهنگ در IndexedDB مرورگر.
- ذخیره‌ی پیش‌نمایش صوتی در صورت اجازه‌ی منبع ו واردکردن فایل صوتی شخصی برای پخش آفلاین.
- رابط نصب‌پذیر PWA و cache پوسته‌ی اصلی برای بازشدن صفحه بدون اینترنت.
- خروجی JSON از پلی‌لیست برای پشتیبان‌گیری.

## انتشار وب با GitHub Pages
در مخزن به Settings → Pages برو، در بخش Build and deployment گزینه‌ی Deploy from a branch را انتخاب کن، شاخه‌ی main و پوشه‌ی /(root) را ذخیره کن.

## راه‌اندازی ربات تلگرام (Cloudflare Pages)
در Cloudflare پروژه را به همین مخزن وصل کن و این متغیرها/Binding را تنظیم کن:
- Environment variable (secret): `TELEGRAM_BOT_TOKEN` — توکن BotFather
- Environment variable (secret): `TELEGRAM_WEBHOOK_SECRET` — یک رشته‌ی تصادفی امن، حداقل 32 کاراکتر
- Environment variable (اختیاری): `TELEGRAM_ALLOWED_USER_ID` — شناسه عددی تلگرام خودت برای خصوصی‌کردن ربات
- KV namespace binding با نام دقیق `MUSIC_KV`

پس از Deploy، آدرس تابع `https://YOUR-DOMAIN/api/telegram` را جایگزین دامنه کن. وبهوک را از سمت خودت تنظیم کن؛ توکن را در چت عمومی یا مخزن قرار نده:
```bash
curl -X POST "https://api.telegram.org/bot$TELEGRAM_BOT_TOKEN/setWebhook" \
  -d "url=https://YOUR-DOMAIN/api/telegram" \
  -d "secret_token=$TELEGRAM_WEBHOOK_SECRET"
```
این فرمان را در محیط امنی اجرا کن که متغیرهای محیطی را تنظیم کرده‌ای. اگر از GitHub Pages خالص استفاده کنی، Pages Functions اجرا نمی‌شوند؛ برای ربات باید روی Cloudflare Pages deploy شود.

ربات دستورهای `/start`، `/help`، `/search عبارت` و `/favorites` و دکمه‌ی ستاره‌دارکردن دارد. فهرست تلگرام در KV و مستقل از پلی‌لیست مرورگر است؛ همگام‌سازی بین وب و تلگرام به endpointهای امن اضافه و در نسخه‌ی فعلی هنوز پیاده‌سازی نشده است.

## محدودیت‌ها
- هیچ API عمومی تضمین نمی‌کند همه‌ی آهنگ‌ها، زبان‌ها، ریمیکس‌ها و ویدئوهای اینستاگرام را پیدا کند. نتیجه به پوشش منبع بستگی دارد.
- تشخیص آهنگ از روی فایل/ویدئو/هام‌کردن نیازمند سرویس fingerprint مانند ACRCloud/AudD و کلید API سمت سرور است؛ کلید را در فرانت‌اند قرار نده.
- پیش‌نمایش‌ها معمولاً کامل نیستند و ممکن است ذخیره‌ی آفلاین آن‌ها از سوی سرویس مجاز نباشد. فایل صوتی شخصی در IndexedDB ذخیره می‌شود؛ ظرفیت به فضای مرورگر بستگی دارد.
- داده‌های وب در همان مرورگر/دستگاه هستند و با تلگرام خودکار همگام نمی‌شوند.
