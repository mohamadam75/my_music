# my_music — موزیک من

وب‌اپ فارسی/RTL برای جست‌وجوی موسیقی چندزبانه، پلی‌لیست ستاره‌دار و ذخیره‌ی فایل‌های صوتی روی دستگاه.

## امکانات نسخه‌ی فعلی
- جست‌وجوی کاتالوگ آهنگ‌ها از iTunes و جست‌وجوی متنی LRCLIB؛ تلاش برای دریافت نتایج Deezer نیز انجام می‌شود و به دسترسی شبکه/CORS وابسته است.
- لینک‌های تکمیلی برای YouTube، متن آهنگ، عکس کاور، Instagram و SoundCloud.
- ستاره‌دار کردن و نگه‌داری اطلاعات آهنگ در IndexedDB مرورگر.
- ذخیره‌ی پیش‌نمایش صوتی در صورت اجازه‌ی منبع و واردکردن فایل صوتی شخصی برای پخش آفلاین.
- رابط نصب‌پذیر PWA و cache پوسته‌ی اصلی برای بازشدن صفحه بدون اینترنت.
- خروجی JSON از پلی‌لیست برای پشتیبان‌گیری.

## انتشار با GitHub Pages
در مخزن به Settings → Pages برو، در بخش Build and deployment گزینه‌ی Deploy from a branch را انتخاب کن، شاخه‌ی main و پوشه‌ی /(root) را ذخیره کن. سپس آدرس GitHub Pages مخزن را باز کن. پس از هر انتشار، اگر نسخه‌ی قدیمی نمایش داده شد کش مرورگر را پاک کن.

## محدودیت‌های مهم
- هیچ API عمومی تضمین نمی‌کند همه‌ی آهنگ‌ها، زبان‌ها، ریمیکس‌ها و ویدئوهای اینستاگرام را پیدا کند. نتیجه به پوشش منبع بستگی دارد.
- تشخیص آهنگ از روی فایل/ویدئو/هام‌کردن نیازمند سرویس fingerprint مانند ACRCloud/AudD و کلید API در سمت سرور است؛ کلید را در فرانت‌اند قرار نده.
- پیش‌نمایش‌ها معمولاً کامل نیستند و ممکن است دانلود یا پخش آفلاین آن‌ها از سوی سرویس مجاز نباشد. آفلاین واقعی فقط برای فایل‌های ذخیره‌شده در دستگاه و در محدوده‌ی فضای مرورگر تضمین می‌شود.
- داده‌های این نسخه روی همان مرورگر/دستگاه هستند و با تلگرام یا دستگاه دیگر همگام نیستند. همگام‌سازی امن به backend و دیتابیس نیاز دارد.
- بخش اتصال تلگرام فعلاً راهنمای اتصال است؛ ربات واقعی تا زمان تنظیم Webhook/Worker و متغیرهای محیطی امن فعال نشده است.

## گام بعدی برای ربات تلگرام
برای راه‌اندازی امن، یک Cloudflare Worker/Pages Function جدا با متغیرهای محیطی `TELEGRAM_BOT_TOKEN` و `TELEGRAM_ALLOWED_USER_ID`، endpoint وبهوک، و Cloudflare D1/KV برای پلی‌لیست مشترک اضافه کن. هرگز توکن ربات را در این مخزن عمومی commit نکن.
